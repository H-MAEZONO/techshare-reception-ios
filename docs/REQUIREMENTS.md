# 要求仕様書（Requirements Specification）

## 1. プロジェクト背景と目的
- **背景:** 社内カンファレンスの受付において、従来の手動名簿チェックによる混雑・待ち時間を解消し、正確かつスピーディな出席者把握を実現する。
- **目的:** 社員証（非接触ICカード）をスマートフォンにかざすだけで、数秒で出席登録が完了し、運営側でリアルタイムに来場状況を一覧・集計できる仕組みを短期間・低コストで構築する。

---

## 2. システム要件

### 2.1 ハードウェア・デバイス要件
- **受付端末:** スマートフォン（iPhone / Android） 2〜3台
  - NFC対応端末（iOS 13以降のiPhone 7以降、またはNFC対応Android端末）
- **読み取り対象:** 社員証（非接触ICカード / FeliCa または NFC Type-A/B）

### 2.2 プラットフォーム・ソフトウェア要件
- **開発・実行環境:** Microsoft 365
  - フロントエンド: Microsoft Power Apps（モバイルアプリ）
  - バックエンド・データストア: SharePoint Online リスト
  - 管理・集計: PCブラウザ（SharePoint リスト標準ビュー / Excel Online）

---

## 3. 機能要件

### 3.1 受付機能（モバイルアプリ）
1. **NFC読み取り機能:**
   - 画面の「タッチして受付」ボタン押下により、端末のNFCリーダーを起動。
   - カード固有識別子（FeliCa IDm / NFC UID）を取得。
2. **出席判定および記録機能:**
   - 取得したカードIDをキーとして名簿マスタを検索。
   - **未受付の場合:** 「出席ステータス: 出席」「出席日時: 現在日時」「受付担当者」を記録。
   - **二重受付の場合:** エラーとせず、「※既に〇時〇分に受付済みです」と画面に注意喚起（日時は上書きしない）。
   - **未登録カードの場合:** 「未登録のカードです（ID: xxx）」と警告表示し、手動確認を促す。
3. **視認性フィードバック機能:**
   - 読み取り結果（氏名、所属、受付時刻、ステータス）を画面中央に大きく表示。
   - 成功時はグリーン、警告・エラー時は赤／黄の背景で直感的に通知。

### 3.2 モニタリング・管理機能（PC / 管理画面）
1. **リアルタイム一覧照会:**
   - 来場者・未着者のステータス一覧をリアルタイム更新で確認。
2. **出席集計表示:**
   - 全体招待数、現在の出席者数、出席率を自動算出。
3. **データエクスポート:**
   - 終了後、Excel / CSV形式でワンクリック出力。

---

## 4. 非機能要件
1. **処理速度・スループット:**
   - 1人あたりの処理時間：2〜3秒以内（タップ ➔ かざす ➔ 判定）。
   - 2〜3台の端末からの同時トランザクションによるデータ競合・欠損が発生しないこと。
2. **セキュリティ・アクセス権限:**
   - 社内Microsoft 365テナント内認証（Azure AD / Entra ID）によるアクセス制御。
   - 受付担当者および運営関係者のみにアプリ・リストへのアクセスを限定。
3. **保守性・可用性:**
   - 専用サーバー構築不要（SaaS環境のみで稼働）。
   - 端末故障時は別の社用スマホでサインインするだけで即座に代替運用可能。

---

## 5. 運用前提・制約事項
- **カードIDの事前把握:**
  - 社員証のFeliCa IDm/UIDと社員番号・氏名が紐付いたリストを事前に総務・情シス部門から提供受けること。
- **連続読み取りの操作性:**
  - スマホOS（特にiOS）のセキュリティ制約により、常時読みっぱなしではなく1人ごとに1回タップ操作を伴う運用とする。
