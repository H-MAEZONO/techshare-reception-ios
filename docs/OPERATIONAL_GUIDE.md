# 運用マニュアル・総務連携チェックリスト（Operational Guide）

## 1. 総務部門・情シス部門との事前連携

### 1.1 相談事項・ヒアリング項目
- **カードID抽出可否:**
  - 入館証管理システム（セキュリティシステム）から、全社員の「社員番号・氏名・ICカード製造番号（FeliCa IDm / NFC UID）」をCSV等でエクスポート可能か。
- **カード種別の確認:**
  - 社員証に搭載されているチップ規格（FeliCa / Mifare / Type-A等）。
  - ※一般的な社員証・入館証はFeliCa（IDm: 16桁の16進数）またはMifare（UID）であり、Power Appsの標準 `ReadNFC()` で読み取り可能です。
- **プライバシー・セキュリティ確認:**
  - 社内イベント受付目的でのIDmデータ利用について問題がないか。

## 2. イベント前日までの準備タスク

- [ ] **マスタ登録:**
  - 総務から受領した名簿CSVをSharePointリスト（`ConferenceAttendees`）にインポート。
- [ ] **受付担当者端末の準備:**
  - 受付担当者（2〜3名）のスマートフォンに「Power Apps」アプリをインストール。
  - アプリの起動確認・アクセス権限付与。
- [ ] **スキャン動作リハーサル:**
  - 受付担当者本人の社員証を用いて、実際の端末で読み取りテストを実施。
  - iPhone（最上部）とAndroid（中央〜上部）のかざす位置を確認・慣れておく。
- [ ] **当日例外対応ルールの策定:**
  - 社員証を忘れた社員、未登録カードだった社員の手動検索・登録フロー（名簿検索画面の用意、または紙名簿併用）。

---

## 3. 当日受付オペレーション

### 3.1 受付ブースの配置
- 受付レーンを2〜3列設置（「受付①」「受付②」「受付③」）。
- 各担当者がスマホを片手に持ち、待受状態にしておく。

### 3.2 受付フロー
1. **声かけ・ボタンタップ:**
   - 来場者が来たら、受付担当者がアプリの「タッチして受付」をタップ。
2. **タッチ・読み取り:**
   - 来場者に社員証をスマホにかざしてもらう（1〜2秒）。
3. **確認・案内:**
   - 画面が緑になり「〇〇さん 受付完了」と出たら「ありがとうございます！」とお声がけ。
4. **例外時の対応:**
   - **画面が黄色（既に受付済み）:** 「〇時〇分に受付完了しております、そのままご入場ください」と案内。
   - **画面が赤色（未登録カード）:** 受付脇の手動確認ブースへ誘導し、PC/タブレットのSharePoint画面で氏名検索・手動ステータス変更を行う。

---

## 4. イベント終了後
- SharePointリスト右上の「Excelにエクスポート」から出席者一覧をダウンロードし、最終出席報告を作成。
